# 阶段一：基础概念

# 1. 基础类型

JavaScript 内置类型在 TypeScript 中的对应关系。

JavaScript TypeScript 示例
number number let n: number = 42
string string let s: string = 'hi'
boolean boolean let b: boolean = true
undefined undefined let u: undefined = undefined
null null let n: null = null
object object let o: object = {}
symbol symbol let sym: symbol = Symbol()
bigint bigint let bg: bigint = 100n

# 2. 特殊原始类型

类型 说明 使用场景
any 任意类型，绕过类型检查 迁移旧 JS 代码
unknown 未知类型，必须做类型收窄 外部数据处理
void 空值，用于函数无返回值 function log(): void
never 从不返回（抛出异常/死循环） function fail(): never

# 3. 字面量类型

类型 = 特定值本身。

type Height = 100 | 200 | 300;
type True = true; // 只能为 true

# 阶段二：类型世界

# 5. 联合类型 (Union Types)

一个值可以是多种类型之一。

type StringOrNumber = string | number;
type Result = Success | Error;

👉 联合类型

# 6. 交叉类型 (Intersection Types)

一个值必须同时满足多个类型。

type Employee = Person & { employeeId: string };
type Draggable = { onDrag: () => void };
type Droppable = { onDrop: () => void };
type DraggableDroppable = Draggable & Droppable;

👉 交叉类型

# 阶段三：结构类型

# 7. 接口 (Interface)

定义对象的结构契约。

interface User {
  id: string;
  name: string;
  age?: number;        // 可选
  readonly email: string; // 只读
}

👉 接口详解

# 9. 泛型 (Generics)

参数化类型，增强代码复用。

// 泛型函数
function firstElement<T>(arr: T[]): T | undefined {
  return arr[0];
}

// 泛型约束
function longest<T extends { length: number }>(a: T, b: T): T {
  return a.length > b.length ? a : b;
}

// 泛型工具类型
type Partial<T> = { [P in keyof T]?: T[P] };
type Required<T> = { [P in keyof T]-?: T[P] };
type Pick<T, K extends keyof T> = { [P in K]: T[P] };
type Omit<T, K> = Pick<T, Exclude<keyof T, K>>;

👉 泛型详解

# 10. 装饰器 (Decorator)

编译时元编程，修改类及其成员的行为。

// 类装饰器
function sealed(target: Function) {
  Object.seal(target);
  Object.seal(target.prototype);
}

// 方法装饰器
function log(target: any, key: string, descriptor: PropertyDescriptor) {
  const original = descriptor.value;
  descriptor.value = function (...args: any[]) {
    console.log(`${key} called with`, args);
    return original.apply(this, args);
  };
}

👉 装饰器详解

# 阶段四：类型编程

# 11. 映射类型 (Mapped Types)

通过变换已有类型的属性创建新类型。

// 可选
type Partial<T> = { [P in keyof T]?: T[P] };

// 只读
type Readonly<T> = { readonly [P in keyof T]: T[P] };

// 键重映射
type Getters<T> = {
  [P in keyof T as `get${Capitalize<string & P>}`]: () => T[P]
};

👉 映射类型

# 12. 条件类型 (Conditional Types)

类型层面的条件判断 T extends U ? X : Y。

type NonNullable<T> = T extends null | undefined ? never : T;

type Extract<T, U> = T extends U ? T : never;
type Exclude<T, U> = T extends U ? never : T;

👉 条件类型

# 13. 条件类型推断 (infer)

从复杂类型中提取部分类型。

// 提取返回值类型
type ReturnType<T> = T extends (...args: any[]) => infer R ? R : never;

// 提取参数类型
type Parameters<T> = T extends (...args: infer P) => any ? P : never;

// 提取 Promise 内部类型
type Awaited<T> = T extends Promise<infer U> ? Awaited<U> : T;

// 递归 infer - 展平嵌套数组
type Flatten<T> = T extends Array<infer U>
  ? U extends Array<any>
    ? Flatten<U>
    : U
  : T;

👉 infer 示例 👉 条件类型推断

# 14. 内置工具类型速查

工具类型 作用 示例
Partial 可选 Partial<User>
Required 必选 Required<User>
Readonly 只读 Readonly<User>
Pick 取部分属性 Pick<User, 'id' \| 'name'>
Omit 排除属性 Omit<User, 'password'>
Record 键值映射 Record<string, number>
Exclude 排除联合成员 Exclude<'a' \| 'b', 'a'>
Extract 提取联合成员 Extract<'a' \| 'b', 'a' \| 'c'>
NonNullable 排除 null/undefined NonNullable<string \| null>
ReturnType 提取返回值 ReturnType<typeof fn>
Parameters 提取参数 Parameters<typeof fn>
