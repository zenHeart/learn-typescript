# 本地类型申明

参考 TypeScript 版本 1.6 Local type declarations (opens new window)

类型申明也和 JavaScript 变量类似存在块作用域。

function funFoo() {
  // 报错无法在此处找到接口申明 T
  let a: T = { a: 1 };

  if (true) {
    interface T {
      x: number;
    }
    let v: T;
    v.x = 5;
  } else {
    interface T {
      x: string;
    }
    let v: T;
    v.x = 'hello';
  }
}
